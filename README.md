# Korea MCT Summit 2026

Korea MCT Summit 2026이 많은 분들의 도움과 참여로 성공적으로 마무리되었습니다.
이 저장소는 행사 종료 인사이트와 발표자료를 한 곳에서 확인할 수 있도록 정리한 공유 공간입니다.

## 행사 종료 요약

- 행사 기간: 2026년 5월 29일(금) ~ 5월 30일(토)
- 장소: 한국마이크로소프트 13층
- 참가자: 67명
- 발표자: 24명
- 운영진: 8명

## 핵심 인사이트

- 기술 확장: GitHub Copilot, Agent Framework, Foundry, Copilot Studio, Power Platform, Kubernetes(eBPF) 등 최신 실무 주제가 폭넓게 공유되었습니다.
- 교육 확장: 기술 전달을 넘어 강의 설계, 자료 제작, 교육 비즈니스 관점까지 토론이 확장되었습니다.
- 커뮤니티 확장: 병렬 세션과 워크숍 중심으로 선택권이 넓어졌고, 행사 이후 학습/피드백 동선이 강화되었습니다.
- 실행 중심 아카이브: 공개 가능한 발표자료를 즉시 연결해 재학습 가능한 형태로 정리했습니다.
