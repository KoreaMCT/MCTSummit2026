# Korea MCT Summit 2026

Korea MCT Summit 2026, 여러분 덕분에 정말 뜨겁고 행복하게 마무리했습니다.
함께 웃고 배우고 연결됐던 그 순간들을 다시 꺼내볼 수 있도록,
발표자료와 사진, 그리고 행사 요약을 이 저장소에 정리해두었습니다.

행사는 끝났지만 우리 커뮤니티의 배움과 도전은 이제 또 다음 챕터로 이어집니다.

## 행사 마무리 한눈에 보기

- 행사 기간: 2026년 5월 29일(금) ~ 5월 30일(토)
- 장소: 한국마이크로소프트 13층
- 참가 대상: MCT / Alumni / Microsoft 임직원 (사전 등록)
- 참가자: 67명
- 발표자: 24명
- 운영진: 8명
- 후원사(공식 페이지 기준):
	- Diamond: Microsoft
	- Platinum: KOSS
	- Gold: 한국트레이노케이트, go deploy, STK
	- Silver: OpenSG
	- Bronze: 한빛미디어

## 이번 행사에서 함께 남긴 인사이트

- 기술 인사이트: GitHub Copilot, Agent Framework, Foundry, Copilot Studio, Power Platform, Kubernetes(eBPF)까지, 실제 현업에 바로 연결되는 주제들이 사례 중심으로 공유됐습니다.
- 교육 인사이트: 기술 자체를 넘어 강의 설계, 자료 구성, 전달 방식, 교육 비즈니스 모델까지 MCT의 현실적인 고민과 해법이 오갔습니다.
- 커뮤니티 인사이트: 병렬 세션과 워크숍 덕분에 각자 필요한 트랙을 더 깊게 선택할 수 있었고, 행사 이후 학습 연결도 훨씬 단단해졌습니다.
- 실행 인사이트: 공유 가능한 자료를 빠르게 아카이브해, 행사 직후에도 바로 복습하고 다시 확장할 수 있는 흐름을 만들었습니다.

## 진심으로 감사드립니다

무대 위에서 경험과 노하우를 아낌없이 나눠주신 발표자분들,
긴 시간 집중해서 함께해주신 참가자분들,
보이지 않는 곳에서 끝까지 행사 완성도를 지켜주신 운영진 여러분께 깊이 감사드립니다.

그리고 든든하게 함께해주신 후원사 여러분 덕분에,
Korea MCT Summit 2026이 더 풍성하고 의미 있는 자리가 될 수 있었습니다.

함께 만들어주신 모든 분들께 다시 한 번 진심으로 감사합니다.
