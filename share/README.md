# Korea MCT Summit 2026 - 행사 종료 인사이트 & 발표자료 공유

Korea MCT Summit 2026이 많은 분들의 참여로 성공적으로 마무리되었습니다.
이 문서는 행사 종료 관점에서 핵심 인사이트를 정리하고, 발표자료를 빠르게 찾아볼 수 있도록 만든 공유 허브입니다.

## 행사 종료 요약

- 행사 기간: 2026년 5월 29일(금) ~ 5월 30일(토)
- 장소: 한국마이크로소프트 13층
- 참가자: 67명
- 발표자: 24명
- 운영진: 8명

## 핵심 인사이트

- 기술 확장: GitHub Copilot, Agent Framework, Foundry, Copilot Studio, Power Platform, Kubernetes(eBPF)까지 최신 실무 주제가 폭넓게 다뤄졌습니다.
- 교육 확장: 단순 기술 전달을 넘어, 강의 설계/자료 제작/교육 비즈니스 모델 같은 MCT 실전 역량 논의가 강화되었습니다.
- 커뮤니티 확장: 병렬 세션과 워크숍 중심 운영으로 참여자 선택권이 넓어졌고, 세션 이후 피드백과 후속 네트워킹 동선이 선명해졌습니다.
- 실행 중심 공유: 공개 가능한 자료를 즉시 모아 후속 학습과 재활용이 가능한 아카이브 구조를 만들었습니다.
